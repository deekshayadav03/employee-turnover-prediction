# Employee Turnover Prediction

## Overview

This project uses Machine Learning to predict whether an employee is
likely to leave an organization.

The project uses Logistic Regression as the classification model.

## Problem Statement

Employee turnover can be costly for organizations. The goal of this
project is to predict whether an employee is likely to leave based on
employee-related features.

## Machine Learning Model

- Logistic Regression
